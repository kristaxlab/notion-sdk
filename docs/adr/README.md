# Architecture Decision Records (ADR)

Lightweight records of significant design choices in the Notion SDK. Each ADR captures **context**, **decision**, and **consequences** so future contributors understand why the model looks the way it does.

| ADR | Title | Status |
| --- | --- | --- |
| [0001](0001-complec-hierarchy-and-deserialization-of-page-properties.md) | Separate `PageProperty` from paginated property retrieve | Accepted |

When adding a new ADR, use the next sequential number and set status to `Proposed`, `Accepted`, or `Superseded`.
